# Gerenciador de gastos em Python

Primeira versão de um projeto de terminal criado para praticar os fundamentos de Python durante o **Curso de Python 3**, de Otávio Miranda, na Udemy.

## Funcionalidades da versão original

- adicionar e listar gastos;
- mostrar o maior gasto e o total;
- filtrar por categoria;
- exibir descrições;
- ordenar registros por valor.

## Como executar

```bash
python versao_original.py
```

Esta versão foi preservada para demonstrar a evolução do projeto. As melhorias serão desenvolvidas em uma branch separada e revisadas por Pull Request.
